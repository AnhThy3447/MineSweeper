# MineSweeper

A classic Minesweeper game built from scratch in Python. The objective is to clear the board without detonating any hidden mines, using numerical clues provided in revealed tiles to flag dangerous spots.

## Difficulty Levels
The game features 4 difficulty levels tailored to different skill levels. 

- **Level 1 (Easy):** 8 Rows × 8 Columns with 7 Mines
- **Level 2 (Medium):** 16 Rows × 16 Columns with 40 Mines
- **Level 3 (Hard):** 24 Rows × 16 Columns with 90 Mines
- **Level 4 (Crazy):** 24 Rows × 24 Columns with 150 Mines


## Controls

- **Left Click:** Open a tile.
- **Right Click:** Place or remove a flag to mark a suspected mine.
